OAO (Open Account Client)
The OAO (Open Account Client) project is a secure, responsive, and feature-rich web-based portal designed for a fintech platform. It streamlines the client onboarding journey, enabling users to seamlessly submit personal information, apply for financial products, review and accept risk disclosures, and submit tax documentation like the W-8BEN form.

Key Features
Client Onboarding Workflow: Multi-step wizard guiding users smoothly from registration to final submission.

Financial Product Application: Allows clients to explore, select, and apply for various fintech products and accounts.

Risk Disclosure & Compliance: Integrated disclosure agreements and legal acknowledgments required for regulatory compliance.

W-8BEN Tax Form Submission: Secure handling and collection of foreign status certification for tax purposes.

Dynamic UI: Interactive and responsive form validations and data bindings for a seamless user experience.

Tech Stack
This application is built using a robust enterprise and frontend technology stack:

Backend: C#, ASP.NET

Frontend Framework: Knockout.js (MVVM architecture)

UI Components: Kendo UI

Scripting & Libraries: JavaScript, jQuery

Styling & Layout: Bootstrap (Responsive Design)
